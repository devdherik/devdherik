## ✅ Boas práticas e como evitar imagens quebradas

1. **Preferência:** hospede imagens críticas no próprio repositório (`/assets` ou `/images`). Isso evita depender de serviços externos.

2. **Fallback automático (exemplo):** mantenha uma versão local do SVG como fallback — coloque `assets/streak.svg` e use:

```html
<!-- Exemplo de fallback simples (não funciona como fallback automático em Markdown puro, mas serve para HTML em páginas) -->
<img src="./assets/streak.svg" alt="Streak do Dherik" />
```

3. **Substituir endpoints instáveis:** troque `profile-counter.glitch.me` por `profile-counter.deno.dev` ou use `komarev.com`.

4. **Verifique hotlinks HTTPS:** sempre use `https://` para evitar bloqueio em páginas seguras.
